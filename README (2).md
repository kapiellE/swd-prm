# SWD PRM – terminal ZRM (makieta do RP)

Symulator tabletu służbowego zespołu ratownictwa medycznego. To makieta, nie łączy się z żadnym prawdziwym systemem.

## Pliki

- `index.html` – cały tablet (grafiki są w środku, nic więcej nie trzeba)
- `README.md` – ten opis

## Jak opublikować na GitHub Pages

1. W repozytorium kliknij **Add file → Upload files**.
2. Przeciągnij `index.html` i `README.md` (zastąpią stare pliki o tych nazwach).
3. Kliknij **Commit changes**.
4. **Settings → Pages**: Deploy from a branch, **main**, **/ (root)**, **Save**.
5. Po 1–2 minutach tablet otworzy się pod adresem strony głównej repozytorium.

## Zapisywanie danych

- Wszystko, co wpiszesz i zapiszesz, zostaje w przeglądarce na tym urządzeniu, także po odświeżeniu.
- Niedokończone formularze są zapamiętywane do czasu kliknięcia Zapisz albo Anuluj.
- W Ustawieniach można pobrać kopię danych do pliku i wczytać ją na innym urządzeniu.
- Dane nie trafiają na serwer. Wyczyszczenie danych przeglądarki je usunie.
