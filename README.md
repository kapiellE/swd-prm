# Bluebird i terminal ZRM (makiety do RP)

Pliki w repozytorium:

- `index.html` – Bluebird (terminal policyjny): `https://kapielle.github.io/bluebirt-do-rp/`
- `prm.html` – tablet ZRM / SWD PRM: `https://kapielle.github.io/bluebirt-do-rp/prm.html`
- `README.md` – ten opis

Każdy plik działa samodzielnie, grafiki są w środku. Nic więcej nie trzeba wgrywać.

## Jak wgrać

1. Wejdź w repozytorium, kliknij **Add file → Upload files**.
2. Przeciągnij `index.html`, `prm.html` i `README.md` (pliki o tych samych nazwach zastąpią stare).
3. Kliknij **Commit changes**.
4. Poczekaj 1–2 minuty. Settings → Pages musi mieć: Deploy from a branch, **main**, **/ (root)**.

## Zapisywanie danych

- Wszystko, co wpiszesz, zapisuje się automatycznie w przeglądarce na danym urządzeniu i zostaje po odświeżeniu.
- Niedokończone formularze też są zapamiętywane, dopóki nie klikniesz Zapisz albo Anuluj.
- W Ustawieniach tabletu ZRM możesz pobrać kopię danych do pliku i wczytać ją na innym urządzeniu.
- Dane nie trafiają na serwer. Wyczyszczenie danych przeglądarki je usunie, więc rób kopię.

To makiety. Nie łączą się z żadnym prawdziwym systemem.
